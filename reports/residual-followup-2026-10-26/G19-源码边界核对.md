# G19：默认出口不自动开放 RFC1918

## 协调者只读源码核对

在实验成员完成默认出口负例后，协调者独立读取精确 Tailscale v1.102.5 源码。未构建或修改上游代码，未运行下载代码。

1. [cmd/tailscaled/netstack.go](https://github.com/tailscale/tailscale/blob/v1.102.5/cmd/tailscaled/netstack.go#L23-L42)：userspace 模式设置 `ProcessSubnets = true`，不能简单归因为 userspace 根本没有子网处理。
2. [ipn/ipnlocal/local.go:3403–3428](https://github.com/tailscale/tailscale/blob/v1.102.5/ipn/ipnlocal/local.go#L3403-L3428)：默认广告路由经 `shrinkDefaultRoute` 加入本机可接收目的集合；注释明确默认出口类似 guest Wi-Fi，只提供 Internet，LAN 需另外显式广告。非默认广告路由直接加入可接收目的集合。
3. [local.go:3543–3547](https://github.com/tailscale/tailscale/blob/v1.102.5/ipn/ipnlocal/local.go#L3543-L3547) 及 [3642–3667](https://github.com/tailscale/tailscale/blob/v1.102.5/ipn/ipnlocal/local.go#L3642-L3667)：默认路由明确剔除 `192.168.0.0/16`、`172.16.0.0/12`、`10.0.0.0/8`。因此本实验的 `10.42.*` PodIP 和 `10.43.*` ClusterIP 都在该边界内，而非仅 ClusterIP 特例。
4. [wgengine/filter/filter.go:218–226](https://github.com/tailscale/tailscale/blob/v1.102.5/wgengine/filter/filter.go#L218-L226) 及 [502–508](https://github.com/tailscale/tailscale/blob/v1.102.5/wgengine/filter/filter.go#L502-L508)：入站包必须既属于 `localNets` 又符合控制面匹配规则。只检查原始 PacketFilter 的 `0.0.0.0/0` 不能证明该包通过了全部本机过滤；目的不在localNets时返回 `destination not allowed`。
5. [net/tstun/wrap.go:1097–1100](https://github.com/tailscale/tailscale/blob/v1.102.5/net/tstun/wrap.go#L1097-L1100)、[1154–1204](https://github.com/tailscale/tailscale/blob/v1.102.5/net/tstun/wrap.go#L1154-L1204)：FromPeer 捕获发生在主过滤之前。观察到 SYN 只能证明解密后到达捕获点，不能证明已进入 netstack TCP forwarder。

## 对实验判断的修正

默认出口批准后私网仍不通，与该安全边界一致；不应仅因控制面通配 ACL 或抓到 SYN，就归结为未明的 Tailscale 转发 bug。`autogroup:internet` 对私网无授权是另一层规则，换成通配 ACL 也不能代替显式 LAN 广告。

据此在相同版本与安全约束的新建隔离环境中，执行显式 `/32` 子网广告及批准／撤销／恢复对照；四阶段内固定同一后端的PodIP和ClusterIP目标，维持权限和超时。两种模式分别使用独立namespace，不宣称跨运行地址完全相同。该对照验证合法私网配置，不把子网通过改写为“仅默认出口的私网通过”，更不能删除上游安全拒绝。

当前源码解释不冒称历史系统调用或逐包 drop trace。随后独立 `/32` 控制已实际完成，run `0feb8335414f`，退出 0：两个目标均未批准失败→批准 HTTP200+marker→撤销失败→恢复 HTTP200+marker。四阶段 R 原生健康，A 原生直达均失败；成功请求的目标访问源均为 R PodIP。R 只广告两个精确 `/32`，A 未选择默认出口，权限与超时不变。见[原始结果](g19-0feb8335414f-result.json)及[最终核验](G19核验.md)。

据此可以纠正本次实验预期／配置：仅默认出口不提供私网通达；显式授权的子网路径可工作。未修改 Web UI 或上游二进制，也未把子网阳性改记成默认出口阳性。原默认出口退出 2 的历史记录与各次夹具失败全部保留。
