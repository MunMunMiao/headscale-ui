# G19：默认出口安全边界与显式私网路由核验

日期：2026-10-26。

## 最新结论

**G19 已闭环为实验预期/配置问题，不是本轮证据支持的 Web UI 或 userspace 转发缺陷。** 精确 v1.102.5 源码表明：默认出口刻意排除 RFC1918；控制面 PacketFilter 通配允许，不能替代本机 `localNets` 的目的地址资格。合法私网访问需要另外显式广告并批准对应网段。

单次新增 `--subnet` 实验只广告本轮 PodIP/32、ClusterIP/32，关闭默认出口、清除 A 的出口选择，沿用原开放 ACL 和全部安全上下文。实际退出 **0**，耗时 **102.431 秒**；同两个目标完成 **未批准失败→批准200→撤销失败→恢复200**，正例均有正确 marker、R 出站来源和双端收发计数增加。

修正的是实验配置与成功判定，不改 Web UI 或上游安全检查。**显式子网通过不等于默认出口私网通过。** 之前退出2的默认出口结果、抓包和准备失败记录全部保留，未覆写为成功。

Run `0feb8335414f`，namespace `hs-g19-1026-0feb8335414f`。同一 T 后端：PodIP `10.42.0.160`、ClusterIP `10.43.157.229`，HTTP/TCP/IPv4 8081，固定 marker `G19_0feb8335414f`。R PodIP `10.42.0.162`。

- R 只广告 `10.42.0.160/32`、`10.43.157.229/32`，全程没有0/0或::/0；A 全程 accept-routes=true、没有 exit-node 选择。
- 同一原开放 ACL，未运行 autogroup:internet、字面 CIDR或默认出口 policy 矩阵。广告、批准路由、A/R netmap、控制面 PacketFilter 均读回；A 的两个 /32 路由按 false→true→false→true 出现/撤回。
- 每阶段都运行 R 同容器原生健康与 A 原生隔离负例；A 经真实 HTTP proxy `127.0.0.1:1056` 发出私网请求，清除绕行代理变量。目标路径只加阶段追踪标记，handler/协议/地址/端口/marker不变。

| 阶段 | 两个 /32 批准 | A→PodIP / ClusterIP | R native健康 | A native直达 |
| --- | --- | --- | --- | --- |
| 新广告未批准 | 否 | 两者 HTTP502、exit1；目标无对应HTTP | 两者200+marker | 两者exit1 |
| 批准两个 /32 | 是 | 两者200+marker、exit0、source=R | 两者200+marker | 两者exit1 |
